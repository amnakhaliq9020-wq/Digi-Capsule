1. Project Overview
Digi Capsule ek digital memory website hai. Users apni family ke liye letters, photos aur videos save karte hain, jo unke chune hue waqt par ya zaroorat parne par un ke apnon tak pohanch jate hain.
Kaam do logon mein taqseem hai:
Amna (Frontend + Copy)
Contacts page
Home dashboard (display only)
Warning email/SMS wording
Test checklist aur handoff
Zamin (Backend + Delivery)
Accounts aur authentication
Memories, check-in scheduling
Warning sending aur delivery logic
Secure APIs aur final approval

Zaroori rule
Kisi bhi page ko Zamin ki approval ke baghair backend se connect nahi karna.

7. Integration aur Ownership Rules
Amna shuru mein frontend ko mock data / agreed API types par banayegi.
Kisi bhi page ko connect karne se pehle: Zamin ko screen link, required endpoints, field names aur test cases bhejein aur explicit approval maangein.
Zamin authentication context aur secure endpoints dega. Frontend code mein secret API keys store nahi karni.
Contacts create / edit / delete sirf logged-in user tak scoped hon.
Memories aur dashboard data sirf authorized APIs ke zariye access hon.
Tamam warning templates: placeholder review, readability review aur final sign-off ke baad hi Zamin send schedule karega.
